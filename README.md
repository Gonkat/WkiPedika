# ⚠️ Учебный демонстрационный проект

## ❗ ВАЖНОЕ ПРЕДУПРЕЖДЕНИЕ

Данный сайт является **учебным макетом**, созданным **исключительно в образовательных целях**.

❌ Сайт **НЕ является настоящим фишинговым ресурсом**  
❌ Сайт **НЕ собирает, не отправляет и не сохраняет пользовательские данные**  
❌ Все формы и поля ввода являются **визуальной имитацией**

Проект используется для **обучения основам кибербезопасности и социальной инженерии**.

---

## 🎓 Цель проекта

Цель данного проекта — **показать наглядно**, как выглядят фишинговые сайты и какими методами злоумышленники:

- вводят пользователя в заблуждение  
- создают ощущение срочности  
- имитируют «повторную авторизацию»  
- заставляют вводить логин и пароль без объяснимой причины  

Это помогает учащимся **распознавать угрозы в реальной жизни**.

---

## ⌨️ Управление (демонстрация)

На странице реализован **учебный сценарий**:

- При нажатии клавиши **`R`**  
  появляется всплывающее окно, имитирующее:
  > «Повторную регистрацию / вход в аккаунт по неизвестной причине»

- Повторное нажатие **`R`**  
  закрывает демонстрационное окно.

⚠️ Данный механизм используется **только для показа**,  
как мошенники визуально крадут данные пользователей.

---

## 🔐 Что важно запомнить

Настоящие сайты:
- ❌ **НЕ просят вводить пароль во всплывающих окнах**
- ❌ **НЕ требуют повторный вход без объяснений**
- ❌ **НЕ используют давление и срочность**

Если сайт ведёт себя подобным образом —  
**это почти всегда признак мошенничества**.
